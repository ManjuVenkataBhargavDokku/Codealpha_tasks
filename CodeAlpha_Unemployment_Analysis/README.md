## Project Overview

This project was developed as **Task 2** of the **CodeAlpha Data Science Internship**.

The objective of this project is to analyze unemployment trends in India using Python. The project focuses on cleaning the dataset, exploring unemployment statistics, visualizing trends, studying the impact of COVID-19, and generating insights that can help understand employment patterns.

---

# Objectives

* Analyze unemployment data of India.
* Clean and preprocess the dataset.
* Visualize unemployment trends.
* Study the impact of COVID-19 on unemployment.
* Perform state-wise unemployment analysis.
* Identify seasonal and monthly unemployment trends.
* Generate meaningful insights from the data.
